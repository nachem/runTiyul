# RunTiyul v1.4.3

Release notes dated 2026-09-22<br>
App version: `1.4.3+13`

The center-to-view button now preserves your manually chosen zoom. Zooming to
fit the whole route is available through a separate, explicit control.

## Changes

- **MAP-008:** the existing center-focus icon is **Center view (keep zoom)**.
  It recenters around the current route, track, checkpoints, selected area, and
  known location without changing zoom or map orientation.
- Empty-content centering leaves the view unchanged. Center view and GPS
  recenter both preserve manual zoom and cancel pending startup placement.
- A separate **Fit route and content (adjust zoom)** button intentionally
  adjusts zoom to frame everything. Automatic route previews keep their
  existing fit behavior.

## Validation

- Reproduced the previous behavior: center-view changed z17.25 to z15 for a
  single location and to z16 for a route.
- All 28 focused map/control tests passed, covering fractional manual zoom,
  course-up rotation, route and selected-area centering, independent callbacks,
  empty-content startup races, explicit Fit, and automatic route fit.
- Full local Flutter suite: all 312 tests passed. Formatting checked 101 Dart
  files without changes; `flutter analyze --no-pub` passed with no issues.
- Removed an empty test file and an unused local left by earlier committed
  download-editor changes; that existing editor behavior is preserved.
- Complete committed-source CI and artifact results are recorded in the
  release wiki when available.
