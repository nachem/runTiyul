# RunTiyul v1.4.2

Release status: [published 2026-09-22](https://github.com/nachem/runTiyul/releases/tag/v1.4.2)<br>
App version: `1.4.2+12`

This hotfix stops a delayed startup GPS response from resetting the map zoom
after the runner uses the zoom or current-location controls.

## Fixes

- **MAP-008:** zoom buttons immediately cancel pending automatic startup camera
  placement. An older GPS request can no longer reset the chosen zoom to z15.
- Current-location recenter cancels that automatic placement before waiting
  for GPS, then uses the live zoom when its fix arrives. Further manual zoom
  adjustments made during the wait are retained.
- Untouched startup still opens at neighborhood zoom. Explicit Fit remains
  separate; course-up orientation and download-provider permissions are
  unchanged.
