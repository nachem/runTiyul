# RunTiyul v1.4.2

Release notes dated 2026-09-22<br>
App version: `1.4.2+12`

This hotfix stops a delayed startup GPS response from resetting the map zoom
after the runner uses the zoom or current-location controls.

## Fixes

- **MAP-008:** zoom buttons immediately cancel pending automatic startup camera
  placement. An older GPS request can no longer reset the chosen zoom to z15.
- Current-location recenter cancels that automatic placement before waiting
  for GPS, then uses the live zoom when its fix arrives. Further manual zoom
  adjustments made during the wait are retained.
- Untouched startup still opens at neighborhood zoom. Explicit Fit remains
  separate; course-up orientation and download-provider permissions are
  unchanged.

## Validation

- Reproduced the v1.4.1 defect with a delayed GPS response: expected z17.25,
  actual z15 before the fix.
- All 13 local route/map widget tests passed, including both GPS completion
  orders, zoom-in/zoom-out independently, zooming while recenter waits, and
  untouched startup.
- The existing recenter test now uses fractional zoom different from the
  default, so resetting to z15 cannot accidentally pass it.
- Changed Dart files were formatted; focused map/test analysis passed.
- Complete committed-source CI, platform builds, and public artifact
  verification are recorded in the release wiki when performed.
