# Support

RunTiyul is a volunteer-maintained open-source project and does not provide an
emergency, rescue, or guaranteed-response service.

## Get Help

- Ask usage, setup, and contributor questions in
  [GitHub Discussions](https://github.com/nachem/runTiyul/discussions).
- Report reproducible bugs with the
  [bug report form](https://github.com/nachem/runTiyul/issues/new?template=bug_report.yml).
- Propose product changes with the
  [feature request form](https://github.com/nachem/runTiyul/issues/new?template=feature_request.yml).
- Read the [developer setup guide](docs/wiki/05-local-debugging.md) and
  [verified implementation status](docs/wiki/02-implementation-status.md).

Search existing issues and discussions before posting. Remove exact
coordinates, GPX tracks, home locations, credentials, and signing information
from screenshots, logs, and attachments.

## Security and Conduct

Report suspected vulnerabilities privately as described in
[SECURITY.md](SECURITY.md). Do not disclose vulnerability details in an issue or
discussion.

For confidential Code of Conduct reports, use the repository's
[private reporting form](https://github.com/nachem/runTiyul/security/advisories/new)
and identify the submission as a conduct matter.

Support is best effort. Response times depend on maintainer availability and
the information provided.
